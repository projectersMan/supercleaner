# 清理中心全部默认项实施计划

目标：底栏执行全部已默认勾选项；各模块显示非零的默认清理容量和操作数量；底部覆盖说明与安全卡移到头部、扫描按钮行上方；扫描按钮加大并与标题文字左对齐，清空废纸篓按钮加大并右移。

设计：复用 DefaultCleanupPolicy、DefaultCleanupSelection、CleanupSelection 与现有执行协调器。系统推荐项、大文件预选项与 Agent 自动预选项汇总；用户取消勾选后排除。应用卸载、本地模型、项目产物仍为手动选择，不加入默认清理。各行与底栏使用同一可执行候选集合，合并重复路径与父子目录，保持执行前安全复验和恢复流程。

技术：Swift 6、macOS 13 原生 SwiftUI；无新增依赖。采用现有工作区保留所有既有未提交修改，直接执行用户已明确的要求，不提交或推送。

## 复核重点

1. 手动勾选的应用/模型/项目和非推荐大文件不得混入；用户取消默认勾选后底栏同步减少。
2. Agent 自动预选异步更新必须使汇总缓存失效；不把人工选择的 Agent 内容视作自动项。
3. 扫描中/失败/未就绪模块不得执行；已有完成模块允许独立清理，更新磁盘显示和各模块回执。
4. 跨维度路径重复或父子重叠只执行一次；容量与最终计划一致，保护项和旧失败项排除。
5. 无默认项或零容量的模块不显示零统计；最小可用窗口仍能访问全部六行且不增加滚动。

方案复核：仅更名底栏会留下系统专用执行路径，必须统一真实候选集合。沿用已有候选来源和一个执行计划，避免为各模块复制执行器或引入新清理规则。

评分：局部统一汇总与执行口径 100、头部布局调整 96；全局复用安全执行及明确手动选择边界 100，均实施。无其它待扩展建议。根目录当前无 AGENTS.md 或 .trae/rules/project_rules.md，不新建 Python 依赖文件。

独立审查修复：P1，系统安装包别名或父目录提前合并会遮蔽大文件保留证明。新增 buildPlan(using:) 将完整候选交给 PlanBuilder 先验证再合并；执行和回执采用最终 plan.selectedItems。真实副本证明测试已观察同路径及父目录两次断言失败，修复后 5 项专项测试通过。没有遗留审查问题。

异步边界修复：Agent 自动预选重算和展示准备期间暂不暴露旧默认父项，避免用户取消子项后在重算完成前执行旧父目录；其他完成模块仍可操作。已用实际 AppModel 状态验证 RED，修复后接入导航 GREEN 和包验证。

反馈补齐：计划校验失败进入现有 failed 状态，底栏展示实际错误；再次启动时清除旧失败状态，避免安全拒绝后按钮无反馈。

最终结果：305 项 Release 测试、核心契约、1259 条双语检查、完整包验证和 DMG 检查通过。原生页面与渐进只读扫描确认系统 319 项/11.85 GB 与底栏一致，手动及无默认项模块不显示零值；最终签名包已更新安装并重开空闲首页。见 [0.4.7 交付](release-0.4.7.md) 和 [逐文件审计](../Tests/dashboard-all-default/README.md)。
