# 项目安装包发现归属与标题栏跟踪

目标：项目 DMG 从发现阶段就属于 Project，不再先出现在大文件统计后消失；窗口状态变化后标题栏和实际侧栏分隔线继续对齐。

- [x] ProjectArtifactScanner 共用工程归属识别；大文件模块在发布前排除项目根范围内已识别工程的 DMG，清单和容量树一起排除。
- [x] 项目模块独立完成 DMG 内容核验和副本保留证明，不依赖大文件模块先产出；保留下载 DMG 原行为与用户配置的项目根。
- [x] 删除手动透明标题栏桥接与隐藏工具栏背景，由原生 NavigationSplitView 和 unified 工具栏统一管理侧栏材料与边界；不硬编码位移、宽度或绘制另一条假分隔线。
- [x] 补发现阶段/渐进顺序和项目独立副本回归，运行定向与完整检查；更新当前文档和逐文件说明；构建脚本自动递增，打包并原生核对普通/全屏、侧栏收放。

反思：仅在最终报告去重虽然总量正确，仍会造成临时统计跳变；过滤必须在发布前，副本约束也必须由项目自己产出。标题栏原桥接只设置透明，没有处理状态变化后的原生跟踪绑定；不通过固定补丁掩盖动态布局。

局部建议：发现阶段归属 100/100；标题栏跟踪 98/100。全局建议：项目模块独立核验与单一原生分栏边界 99/100，均执行。保留全部既有未提交修改，不提交、不推送，无新增依赖。两处规则文件仍不存在。
