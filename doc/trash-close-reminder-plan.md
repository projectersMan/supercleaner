# 关闭窗口时的废纸篓提醒

## 目标与方案

本次累计清理容量大于 0 时，在用户关闭主窗口或直接退出应用前显示原生提醒，引导用户检查并清空系统废纸篓以释放空间，提供跨重启生效的“不再提醒”。使用现有会话统计，不检测或删除废纸篓内容，不把累计清理量当作实际释放空间。

采用 NSWindow.willCloseNotification 观察主窗口，保留 SwiftUI 自身的窗口 delegate 与 Dock 重开行为；应用直接退出复用同一提醒状态，保留原有更新退出门禁。原生 NSAlert 提供“打开废纸篓”和继续关闭/退出两条路径。相同累计容量确认后不重复提醒，有新增清理后重新提醒；永久关闭提醒保存在 UserDefaults。

仅在退出回调提醒会漏掉红色关闭按钮；替换 SwiftUI 窗口 delegate 会干扰窗口生命周期，均不采用。打开废纸篓失败时显示明确错误。按用户后续反馈，弹窗正文压缩为“本次已清理 {0}，清空废纸篓以释放空间。”容量保持“已清理”口径，不承诺清空废纸篓能释放全部累计容量。

## 约束与复核重点

- Swift 6 / macOS 13，复用 AppKit、Foundation 和现有 SwiftPM 依赖，不新增 Python 包或 requirements.txt。
- 不重置本次累计统计，不修改扫描、删除、恢复和系统权限策略。
- 0 字节不提醒；永久关闭后跨进程不提醒；一个会话同一容量不连续提醒；新增清理可再次提醒。
- 最小化、关闭其他面板和取消更新退出不触发提醒；仅主窗口注册关闭通知。
- 根目录 AGENTS.md 和 .trae/rules/project_rules.md 均不存在，不创建额外规则文件。保留原有未提交改动。
