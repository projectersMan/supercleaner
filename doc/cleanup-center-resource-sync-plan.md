# 清理中心资源汇总与安装包活动范围修复计划

> 实施方式：在当前工作区逐项执行，保留所有既有未提交修改；不提交、不推送。

**目标：** 清理中心纳入项目和模型仍勾选的可清理项，移除两资源页头部按钮，将工程内 DMG 归到项目并恢复未使用安装包的识别。

**架构：** DefaultCleanupSelection 统一六维度的展示和全部默认计划；资源资格继续复用 ResourceCleanupListPolicy。构建目录活动与具体打开文件分开，项目扫描保留完整活动范围，普通大文件不因构建进程 cwd 被整目录保护。

**技术：** Swift 6、SwiftUI、Foundation；无新增依赖。

## 约束与反思

- 项目/模型的预选已经存在，首页却硬编码为空，是上轮接线遗漏。只补文案会留下底栏总量与实际计划不一致，必须共用同一个集合。
- 模型和项目活动、保护、不完整、失败项、手动撤选继续排除；扫描中或项目根待刷新不能执行旧结果；应用卸载仍手动选择。
- 扩大 DMG 的识别不能删除活动保护；只隔离构建工作目录，显式活动文件和缓存目录的保护继续有效。
- 用户确认前不执行任何真实清理。验证只构建计划、只读扫描。
- 编译脚本自动递增版本一次；不手动改版本，不为单独打包递增。
