# 大文件与 Agent 默认空列表回退计划

目标：检查大文件与 Agent 是否默认展示可删除/已选中列表；默认页为空时显示 All，手动筛选不被覆盖。

现状与方案：大文件 showsDuplicateLargeFilesOnly 默认 false，初始就是 All Large Files，保留现状，不新增可删除范围，也不把手动空重复筛选改回 All。Agent 默认 Selected；用可选的手动覆盖值区分自动默认与用户选择。自动时按当前 Skill/MCP 类型及平台判断已选中列表是否有项目：有则 Selected，无则 All。异步建议到达可自动恢复 Selected；手动选择后保持。类型变化须清理可见列表缓存；在每次过滤前解析一次有效范围，避免逐条计算带来平方复杂度。

技术与约束：Swift 6/SwiftUI/macOS 13，无新依赖；沿用当前工作区，保留前序未提交修改，不提交或推送；根目录无 AGENTS.md 或 .trae/rules/project_rules.md。所有验证资料在 Tests/agent-empty-default-scope；不会清理真实内容或更改权限。
