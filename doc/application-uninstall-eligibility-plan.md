目标：第三方应用的卸载资格不由运行状态、输入法类型或静态写权限决定；系统保护、运行状态与执行授权分别处理。

错误链路：扫描器将全部输入法标记为系统应用；`canMoveDirectory` 的写权限预检结果进入永久保护字段；筛选、分析、计划生成及执行复核复用该错误字段。只改列表会留下无法生成或执行计划的问题。

方案：删除静态管理员权限预判及其持久化字段，受保护范围保留系统应用；三个非 All 范围互斥：系统应用只在 Protected，非系统应用根据运行状态进入 Running 或 Uninstallable；实际权限错误沿用现有授权/重试流程。输入法仅开放第三方安装目录中的 app 本体，通用缓存清理保护继续保留。

补充要求：Running 仅显示非系统运行中应用；Siri AI 等系统应用无论运行状态都保留在 Protected 和 All。第三方输入法可勾选退出，系统应用不显示可操作的退出复选框。

最新纠正：上一轮将 Running 与 Uninstallable 作为可重叠范围是错误理解。按用户明确要求改成互斥分类，不恢复第三方应用的错误权限保护。局部修正 100 分：Uninstallable 排除运行中应用，并移除该范围的退出按钮；全局配套 99 分：加入分区无重复/无遗漏及启动/退出迁移回归，同步模型自检、契约和文档，更新固定签名安装副本。
