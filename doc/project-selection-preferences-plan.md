# 项目筛选与默认勾选设置实施计划

目标：Project Artifacts 保留 All / Protected / Selected，移除 Cleanable。Git 已跟踪产物允许手动选择；设置开关决定是否自动勾选项目产物（包括 Git 跟踪项），默认关闭。关闭时项目手选且不加入首页默认队列；开启时通过检查的项目可自动勾选。继续只编译打包，不提交、不推送。

设计：复用现有 requiresExplicitSelection 表达 Git 跟踪证据，自动勾选由 DefaultCleanupPolicy 的项目开关统一决定。模型继续保持原分类和手选。AppModel 持久化新偏好并跟踪自动选中 ID，关闭开关只撤销自动选择，保留人工决定。项目默认有选项用 Selected，否则 All；用户主动筛选保持。

- [x] 先补红灯：Git 跟踪 DMG（含 .build/checkouts 嵌套库）可手选、无自动副本证明；目录 Git 跟踪可审查，凭据/嵌套库/活动/未知 Git 状态仍受保护；隔离测试证明计划、执行和恢复。
- [x] 默认队列测试覆盖开/关、手动选择不进入关闭的首页队列、模型不受影响。扫描器仅把已确认 Git 跟踪从不可选改成审查，手选快照保留路径/权限/保护/包/云盘边界；跟踪项不参与自动副本配对。
- [x] Settings 加“默认勾选项目编译产物（包括 Git 跟踪项）”，默认关闭、持久化、忙碌时不可改；切换对已有报告即时生效，不重扫、不清空人工选择，首页统计缓存同步失效。
- [x] 资源筛选项由维度决定，使用标签位置映射实际 scope，避免删除 Cleanable 后索引错位；项目默认 Selected/All，模型保持原逻辑。补首次/渐进/重扫、开关开关及持久化自检。
- [x] 定向与完整构建、应用包自检和原生只读观察，更新 README、doc/、docs/ 及逐文件验证；由脚本自动递增并打包供用户测试。

反思：仅解禁复选框而不改执行复验会形成“可选却删不了”；仅按 selectable 自动全选会把 Git 手选项误放入首页。开关、默认选择、执行与首页队列必须统一。默认关闭是本轮明确采用的产品默认；安全检查失败不可通过开关放开。局部：手动可选与自动默认分离 100/100；全局：单一默认队列策略、保留人工选择和不削弱执行边界 100/100，均实施。无新增依赖，Swift 项目无需 requirements.txt；根目录规则文件不存在，保留全部前序未提交修改。
