# 清理中心选择与完成统计

目标：六个维度回到清理中心后显示当前选择的数量、容量，并独立显示本次会话成功清理累计；每个中心行的已清理项数、容量之和严格等于右上角总计。

方案：复用 AppModel 的选择状态，不另外缓存首页选择。提取按维度读取选择的方法；推荐与手动混合时显示“已选”，纯手动显示“手动已选”。已清理与待清理分两行，重新扫描保留会话累计。保持右上角既有成功文件操作计数口径，不改详情页模型数或卸载凭据数；失败/跳过不计成功，同一回执只累加一次。容量表示成功处理内容的逻辑大小，实际磁盘可用空间继续由侧栏独立读取。

约束：保留已有未提交修改，不提交或推送；Swift 项目，无新增依赖；工作区不存在 `.trae/rules/project_rules.md`。测试素材置于 Tests。手动选择仅展示，不改变“清理全部推荐项”的执行范围。
