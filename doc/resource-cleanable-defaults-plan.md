# 资源页 Cleanable 默认展示与预选计划

目标：清理中心模块行内 Default 改为 Cleanup；Project Artifacts 和 Local AI Models 扫描完成后，有可清理项就展示 Cleanable 并勾选这些项，没有则展示 All。默认仅作用于本模块的新扫描结果；用户之后的取消勾选、搜索、排序和导航不触发重新预选。

架构：复用 AppModel 的 selectedIDs、resourceReviewFilters、渐进模块发布与 ResourceCleanupListPolicy.isSelectable。只在对应资源模块发布成功结果或首次安装一个新 generation 报告时应用预选；最终整批汇总及其它模块更新不覆盖手动决策。活动、blocked、不完整和永久保护项继续不可选；确认删除与执行复验保留。两个资源维度仍不进入首页全部默认清理队列，Core 候选的风险/显式选择标记不改。

技术：Swift 6、SwiftUI、macOS 13，无新增依赖。沿用现有工作区，保留全部既有未提交修改，不提交或推送；根目录无 AGENTS.md 和 .trae/rules/project_rules.md。遵循先计划再代码，过程材料放在 Tests/resource-cleanable-defaults。

反思：在进入页面时自动全选会覆盖用户保留决策；仅把 scope 初始值改成 cleanable 无法处理空列表和异步扫描。将默认值应用放到模块新结果发布处，能与现有渐进扫描/继续扫描边界一致。Core 的安全资格与首页默认清理范围不应因 UI 预选而扩大。
