# 清理中心单页与清空废纸篓实施计划

目标：按用户两张截图，将首页整理为无需上下滚动的单页。扫描按钮及其下方用时、紧凑卷容量、累计清理量组成同行等高的三个区域；累计清理下方提示替换为清空废纸篓按钮。

用户追加要求：本地 AI 模型、项目产物两页参考应用卸载与重复大文件页统一排版与操作。保留 ResourceCleanupView 两个入口，使用一致的紧凑标题/搜索筛选、可勾选分组列表与详情区域；支持筛选、排序、分组选择及查看详情，手动选择和阻止项保护继续有效，不额外引入新清理策略。

沿用原生 SwiftUI 和现有状态，移除 Dashboard 的 ScrollView，缩小标题、间距与模块行；六个导航和底部安全卡保留，长说明可通过 tooltip 查看。按 detail 最小 760×560 pt、默认 1280×820 pt 窗口、中英两种语言验证，不提高最小窗口尺寸掩盖溢出，不改扫描或清理默认规则。采用现有布局容器，不增加通用布局框架或依赖。

废纸篓由 Finder 执行清空，用户点击后先显示不可恢复的确认；取消不执行。复用有超时与输出限制的 BoundedProcess 异步调用固定系统工具，主线程不等待脚本执行，不直接遍历/删除 Trash。补充 Automation 用途描述及正式签名所需 Apple Events entitlement；本轮验证不发送真实清空命令、不授予系统权限。

复用同一个 TrashReminderController 管理关闭和退出提醒。仅成功清空后记录点击时的累计清理字节，保留用户已有“不再提醒”偏好；随后有新清理内容时可再次提醒。失败、取消、超时不得伪装成成功；操作结束刷新卷容量，等待期间阻止重复清空与并发清理/退出。该会话确认不得写成永久关闭提醒。
