# 0.3.35 当前页面全选与两态勾选

## 修改

- 应用卸载总框只显示勾选和空框。全部可选子项选中时打钩，部分子项选中时显示空框；点击空框会补齐普通文件及安装收据的选择，取消总框会清除全部子项。
- Agent 页筛选栏增加“全选”复选框，Skills、MCP 共用。只处理当前类型、平台和显示筛选后展示的可选项目，包含滚动列表中的项目；不改变隐藏项目的已有选择。
- 全选使用稳定的当前列表快照批量更新；取消“已选中”列表中的全部选择时，不会因列表逐行消失而漏项。
- 批量操作一次写入手动选择决定、一次发布所选 ID，并使旧的预选计算失效，避免旧结果覆盖当前手动决定或重算隐藏项目的选择。保护项、执行与扫描状态限制继续生效。
- 全选属于用户主动操作；全局资源仍不被自动预选，跨平台重叠分析规则不变。

## 验证范围

- AppModel Agent 自检覆盖 Skills/MCP 全选、平台与类型筛选、受保护项、手动选择全局资源、隐藏的手选/自动选择保留、取消已选列表，以及执行/扫描期间禁止修改。
- 应用卸载自检继续覆盖普通文件、安装收据及清空选择的一致性。
- Debug、Release 各 226 项测试通过；CoreContractChecks、双语资源校验和打包后应用自检通过。
- Computer Use 使用真实 AgentEnvironmentView、ApplicationsView 和 AppModel 的隔离数据完成验证：Skills/MCP 全选，取消单项后的空框，平台筛选下只清除展示项，隐藏平台及另一类型的原选择保留，以及在“已选中”列表中一次取消全部当前项。未执行真实清理或卸载。
- DMG 内部应用签名、结构及 CRC 校验通过。模型源文件已恢复为 134 字节 Git LFS 指针。
