## 不应混同为扫描截断的限制

| 类型 | 位置及例子 | 结论 |
|---|---|---|
| 外部命令防挂起 | BoundedProcess.swift 默认 5 秒、输出 1 MiB；ps 3 秒；lsof 5 秒 / 4 MiB；git 3 秒；ZIP 命令约 3 秒 | 建议保留；需要更完整结果时采用分页/流式输出。直接取消优先级 **15** |
| 特权永久清除边界 | HelperFileOperations.swift 最多 100,000 项、64 层、20 秒 | 这是授权后的特权递归删除，不是扫描；本次未改。若要支持超大清除，应改成分批并续签授权，不能直接删除全部边界。直接取消优先级 **10** |
| 权限请求预热 | PermissionStatus.swift 对部分应用数据根最多向下探测 2 层 | 仅用于提前触发系统权限提示，后续实际扫描不受此深度影响；取消会重复完整扫描。直接取消优先级 **5** |
| 源码/结构解析防异常嵌套 | ApplicationDataDiscovery.swift 模板表达式嵌套 64 层；归档及 JSON 结构合法性检查 | 不是文件目录深度；应保留或改成有界迭代解析。直接取消优先级 **5** |
| 并发数量 | 应用分析及删除前批量验证通常最多 4 个并行任务 | 控制同时运行数量，不减少最终处理数量；保留。直接取消优先级 **0** |
| 模型/网络/下载 | 模型输入片段大小、推理超时、网络请求超时、下载体积及重定向限制 | 属于资源或协议边界，应分别调优，不能作为目录扫描上限直接删掉 |
| 展示条数 | Agent 相关目标摘要最多 3 个、标签/引用预览的 prefix 等 | 只影响摘要展示，不意味着扫描未计算；不在本次取消范围 |
| 业务扫描范围 | 已知缓存根、应用包边界、ZIP 同级目录匹配等 | 是识别规则的范围，不是“扫描太久就停”；扩大范围需要独立评估准确性 |

因此不能把所有名为 limit/maximum 的值一起删掉。优先消除的是“扫描到一半因为总时间或总数量停止”的限制；字节读取、子进程防挂起及特权执行边界需要换成完整但有资源控制的实现。
