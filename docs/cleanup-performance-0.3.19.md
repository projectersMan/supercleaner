# SuperCleaner 0.3.19（93）交付记录

## 实际修改

1. 清理规则不再按条目数量、目录层数提前结束。磁盘、应用、Agent、安装包、项目产物和历史残留的普通目录扫描也移除了深度截断。任务取消、不跟随符号链接、访问失败报告继续生效。
2. 完整扫描通过的清理对象带有已验证范围信息。删除时复用它，只核对当前路径、对象身份、规则状态、保护清单和固定的敏感内容入口；不再递归计算整个目录。未验证对象以及共享资源等仍执行各自必要核对。
3. 应用本体卸载直接读取所选应用，不为它重新发现所有应用。关联数据仍需针对归属变化核对；应用在移动前的重复全面核对改为运行状态及保护核对。
4. 清理期间保留轻量进度更新，结束后统一更新列表，避免每 150 毫秒重新计算所有模块。路径匹配使用内存索引和父路径查询，消除“每个列表项 × 每条删除结果”的文件系统路径检查。
5. 清理时暂停竞争资源的 Agent 包含关系分析，清理结束后恢复。
6. 经过完整检查、可再生的普通用户缓存/日志进入推荐清理，运行状态本身不再让这类缓存自动留在保留组。凭证、用户数据、离线内容、链接等仍按具体证据处理；Playwright 浏览器运行文件不自动推荐删除。
7. 因访问问题未完成扫描的条目显示“扫描未完成”，避免仅显示“永久保护”造成误解。
