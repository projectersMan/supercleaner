# SuperCleaner 0.3.21（95）交付记录

## 本批次变更

- 根据用户要求，确认没有应用归属的非共享残留默认勾选，放入“推荐清理”。范围包括应用支持数据、偏好设置、独立容器和保存状态，不再统一要求手选。
- 默认推荐必须满足应用清单完整、没有已安装或正在运行的应用所有者、目录检查完成、没有受保护内容。已安装应用的扩展、应用组和偏好设置后缀仍按现有归属规则排除。
- 共享容器、应用清单不完整的条目继续不默认勾选，并解释具体原因。目录检查未完成或含受保护内容的项目不会默认清理。
- 复用原本统计大小的目录遍历核对目录枚举完整性与对象类型，不读取残留文件正文或系统容器元数据；保护清单在根目录检查一次，覆盖受保护子路径。容器内指向桌面、下载等位置的系统链接不会导致误保护；扫描和清理不跟随这些链接，仅处理链接本身。
- 执行时，如果应用清单读取不完整、应用已重新安装或运行，则拒绝清理该残留，避免沿用失效的归属判断。
- 默认勾选会让确认清理包含这些应用的历史设置和数据；仍由用户确认执行，沿用现有恢复流程。本次验证没有清理用户真实文件。
