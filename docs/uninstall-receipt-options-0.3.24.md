# SuperCleaner 0.3.24 (98)

## 修改范围

仅调整应用卸载页面及安装记录的勾选执行行为。系统清理、大文件、Agent、恢复页面的保护标签、图标与显示逻辑已恢复到本批次之前的状态，底层路径保护没有放开。

## 实际变化

- 应用卸载页去掉条目的系统路径保护标签和锁图标。不可直接卸载的明细不作为可勾选文件展示，应用整体仍可在原来的分类中查看。
- PKG 安装记录作为独立的“随卸载清理安装记录”选项显示，默认不勾选，用户可以手动选择。
- 同一个安装包的 `.bom` 和 `.plist` 是一组记录，两个复选框联动。选择不会将它们加入普通文件删除计划，也不会直接删除 `/var/db` 文件。
- 执行计划只携带用户明确选择的安装记录收尾指令；未勾选时不准备该记录的清理工作。取消选择不影响应用本体的卸载选择。
- 对应应用成功卸载且满足安装清单核对条件后才尝试系统记录清理。记录清理失败静默，不改变卸载结果，不新增错误提示。应用本体的真实卸载失败仍按原行为报告。
- 没有新增“下次扫描将失败安装记录视为普通垃圾”的规则。
