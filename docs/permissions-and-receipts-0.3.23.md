# SuperCleaner 0.3.23 (97)

## 本批次实际变更

- 全量扫描入口先刷新磁盘访问状态、后台服务状态及当前管理员授权。首次使用集中显示权限准备页面；当前会话已完成准备、可检查的权限仍然有效时直接扫描。
- 权限准备页面统一提供完全磁盘访问、App 管理和管理员后台服务入口。系统设置返回后刷新状态。保留用户明确选择的“按当前权限扫描”路径，取消准备不会开始扫描或删除。
- 扫描目录访问预检不再仅依赖“以前请求过”标记，每次扫描按当前访问情况执行。历史卸载成功不再被读取为当前 App 管理授权。
- 删除本应用自行设置的管理员授权五分钟期限，改为应用会话内复用；退出、主动撤销、升级或后台服务不可用时释放授权。每个特权请求仍由系统静默验证，不在文件执行器里申请新授权。系统撤销授权不能被应用绕过。
- 增加通用 PKG 安装记录收尾操作。卸载前读取已关联的真实 plist/BOM，绑定内容指纹，核对整个包的应用载荷均属于本次选择。保留其他应用或包中包含其他未纳入的组件时不清理记录。
- 应用文件实际卸载成功且结果确定后，后台服务再次核对安装记录指纹、原安装路径确实不存在，再调用固定系统工具 `pkgutil --forget`。不开放 `/var/db` 普通删除，不运行软件专属脚本，不按厂商或应用名添加规则。
- 安装记录失败仅写内部诊断日志，不增加界面警告，不改变卸载成功结果。取消、失败、待验证结果不触发对应记录清理。
- 安装凭据不再作为两个锁定文件出现在可卸载清单中；安装来源区域说明完整卸载后尝试清理对应记录。
- 内嵌后台组件注明“随主应用卸载，大小已包含”，不重复计算大小或创建重复删除任务。
- Helper 协议版本从 2 升到 3，旧版本后台服务不能被误认为支持新操作。

## 本地包的明确边界

当前机器没有可用 Apple 团队签名证书。此次本地测试包使用临时签名，管理员后台服务仍不可启用，相关记录清理会静默跳过，不能将此包当作真实管理员操作已经验收的发布版。正式团队签名、正确发布 Bundle ID、系统批准后台服务后，才能完成该通道的真机验收。

macOS 的完全磁盘访问、App 管理、后台服务批准是不同权限，无法合并成一次系统弹窗。App 管理没有在本项目中使用的只读授权查询接口，准备页面仅引导用户开启，不伪造“已授权”状态。系统撤销权限或要求额外确认时，无法保证永不出现系统提示。

本次没有改动 SuperCleaner 自身更新器的安装授权，也没有安装证书、修改系统信任设置或自动替换 `/Applications` 中的现有应用。
